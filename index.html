Setup guide

One-time setup. After this, everything is managed from this page.

1

Create a Firebase project

console.firebase.google.com → Add project → create a Realtime Database in locked mode. Enable Authentication → Email/Password, add one user, then block new sign-ups under Authentication → Settings → User actions.

2

Publish database rules

Realtime Database → Rules → replace with the JSON below, then Publish.

{
  "rules": {
    ".read": false,
    ".write": false,
    "secrets":  { "$uid": {
      ".read":  "auth != null && auth.uid === $uid",
      ".write": "auth != null && auth.uid === $uid" } },
    "runtime":  { "$uid": {
      ".read":  "auth != null && auth.uid === $uid",
      ".write": "auth != null && auth.uid === $uid" } }
  }
}
3

Host this page

The firebaseConfig at the bottom of this file is already set for project myhermess. Push the file to a repo as index.html and enable GitHub Pages — it contains no secrets, so public hosting is safe.

4

Add 4 bootstrap secrets to GitHub

Repo → Settings → Secrets → Actions: FIREBASE_API_KEY, FIREBASE_DB_URL, FIREBASE_EMAIL, FIREBASE_PASSWORD. These are the only GitHub secrets you will ever touch again.

Values saved in this vault override GitHub secrets of the same name. Empty fields fall back to GitHub secrets, so you can migrate gradually — nothing breaks while the vault is empty.
